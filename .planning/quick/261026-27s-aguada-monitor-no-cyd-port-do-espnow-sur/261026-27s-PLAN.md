# Aguada Monitor no CYD (port do espnow_survey)

Ferramenta de campo portátil para instalar nodes: CYD ESP32-2432S028R (ILI9341 + XPT2046) ouvindo ESP-NOW ch11.
Requisitos confirmados pelo usuário (2026-10-26 01:35):

1. Novo env `cyd` em `firmware/espnow_survey/` (`src/main_cyd.cpp`), reaproveitando `stats.h`, `crc16.h`, `../shared/protocol.h`, ping de 1 byte e CSV serial. Env `esp32dev` (OLED) intacto.
2. Telas por toque: Lista · Sinal (detalhe + histórico + dados do sensor) · Ping (ACK% p/ GW `8C:D0:B2:A8:AB:D6` ou node) · Log (terminal).
3. LED RGB = veredito do node selecionado; bipe por pacote (Sinal) / ACK (Ping) com mudo.
4. Gravar em /dev/ttyUSB0 (CYD MAC 6c:c8:40:05:a0:f8; backup Mochi em ~/DEV_BOT/backups/). Bin compatível com Launcher (esp32dev 4 MB).
5. Fora: SD log, Wi-Fi/MQTT, promíscuo (rede é toda broadcast).

Tarefas:
- T1 platformio.ini: env `cyd` com TFT_eSPI 2.5.43 via build_flags (sem User_Setup global), XPT2046, build_src_filter separando main.cpp/main_cyd.cpp.
- T2 main_cyd.cpp: rádio (igual survey) + UI sprite 8 bpp + toque + LED + bipe.
- T3 Build, check_stats no PC, gravar, verificar boot pela serial; toque/cores conferidos na placa.

Execução inline no tree principal (espnow_survey é untracked → worktree não o teria; gravação exige o hardware local).
